# Sketch contract

- One complete HTML document with `<html lang="en">`, `<meta charset>` and `<meta name="viewport">`. No JavaScript, no external requests, no images, no web fonts.
- Code inserts the shared sketch kit below at the top of `<head>`. Build with its classes. You may add one small `<style>` block for layout only (grid, flex, widths, gaps, ordering and one breakpoint at 768px). Never set colors, fonts, shadows, radii or backgrounds; the kit owns them.
- Wrap each page section in `<section class="sk-section" data-section="<section id>">`, in the direction's order. Use `header`, `main` and `footer` for the page frame.
- Must read well at 375px and 1440px wide, with no horizontal scrolling at 375px.
- Keep it short: roughly 150–300 lines.
